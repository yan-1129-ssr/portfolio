FAQ

常見問題

這個作品集是用什麼技術做的？

純原生 HTML、CSS、JavaScript，沒有使用 Tailwind 或 React 等框架，方便學習與維護。

可以切換深色模式嗎？

可以。點右上角的主題切換按鈕，或在不同裝置上依照系統偏好顯示。

如何替換成我自己的內容？

主要修改 index.html 裡的文字與連結；配色在 style.css 最上方的 CSS 變數區調整。

支援手機瀏覽嗎？

支援。全站採響應式設計，導覽列在手機上會收合為選單。
